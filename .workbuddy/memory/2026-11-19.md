# 2026-11-19

## 安装 img2threejs（图片→程序化 Three.js 模型 skill）

- 来源 https://github.com/img2threejs/img2threejs（Apache-2.0，21.6k star，v2.0.1）
- 装法：`npx --yes img2threejs@latest install` → 自动链接到本机已检测到的 3 个宿主：`~/.claude`、`~/.codex`、`~/.config/opencode`（`~/.hermes` 不存在，跳过）
- 实际落盘：共享 checkout `~/.img2threejs/releases/0c0c49bc168e648dbaf9c8c080474de0b3a941b6/img2threejs`（8.5M，git clone 形态），三个宿主目录里是符号链接
- **额外手动补链**：`ln -sfn <release> ~/.workbuddy/skills/img2threejs`，让 WorkBuddy 也能加载该 skill
- 校验：`npx --yes img2threejs@latest doctor` 三行全部 `managed → ... (2.0.1)`
- 测试：仓库自带 101 个 unittest 脚本（无 pytest 依赖，`forge/tests/` 无 `__init__.py`，不能 discover）。逐个 `python3 forge/tests/test_*.py` 跑，**必须 `export PYTHONPATH=$PWD`**，否则 6 个用例报 `ModuleNotFoundError: No module named 'forge'`。补 PYTHONPATH 后 101/101 全通过
- 已装：基础 skill；**未装**可选插件 harness（`@img2threejs/img2`，仅 cs2/character 等插件需要，README 明确要求不要默认全装）
- 环境要求满足：Node 22.22.2 / Python 3.13.12 / git 2.52.0；forge 核心纯标准库零第三方依赖
