# 05｜Data 数据模块

## 模块定位

Data 是数据资产面，负责把设备消息、实验文件和运行结果沉淀为可追溯、可治理、可分析的数据资产。

## 数据分层

```text
L0 原始层：设备原始文件、MQTT消息、原始对象
        ↓
L1 标准层：统一时间、单位、字段和设备语义
        ↓
L2 分析层：实验结果、指标、特征和报表数据
        ↓
AI-ready：质量校验、血缘、训练和推理数据集
```

## 数据流

```text
Device / 采集边缘
        ↓ MQTT / 文件 / API
Data Ingestion
        ↓
原始对象存储 + 元数据
        ↓
标准化、质量校验、血缘记录
        ↓
分析结果 / BI / ELN / 模型平台
```

## 边界

- Data 保存数据资产、URI、checksum、schemaVersion、质量状态和血缘。
- Frame 只保存运行上下文和数据资产引用，不搬运大型文件。
- Workflow 展示业务结果，但不直接维护原始数据。
- Data 不负责实验状态机、设备锁或业务审批。

## V1.0 建议

先打通“设备文件或数据流 → 原始落盘 → 资产 ID 返回 → Flow/Workflow 引用”的最小闭环，再扩展标准化、分析和 AI 数据集。
